# DVOTE

A phone-first daily devotion / life game.

DVOTE treats ordinary life as the playable field. The book supplies small encounters; the reader supplies the world.

Core loop:

**OPEN → READ → CHOOSE → GO LIVE → WITNESS → COMPOSE → CLOSE**

Design law:

> Do not gamify the sacred. Game the attention.

No points, streak punishment, spiritual scoring, or claims that coincidence is revelation. DVOTE records what happened, preserves what mattered, and lets patterns become visible over time.
